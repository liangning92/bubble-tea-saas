# AI 设置：连接、能力与审批边界

本次仅重组后台 AI 设置及补齐显式连接验证。保留 PR256 的 workflow 契约和审批检查，不新增经营执行权限，不改生产配置或凭据，不部署。

## 首次使用

必要输入为供应商 MiniMax、服务地区、模型、API key，以及新密钥的数据目的地确认。沿用服务端的模型格式与当前默认模型；连接验证才判断供应商是否接受该模型与凭据，不把可编辑模型名当作供应商可用性保证。

供应商固定展示，不放置未接入供应商选项。地区只显示中国区/国际区，在新密钥的确认处展示官方目的地域名。切换地区立即清空未保存密钥与确认；已有密钥不能跨区沿用。

月估算上限在运行费用区域设置；每百万输入/输出 token 单价折叠在高级区域。单价是内部 API 估算参数，不是订阅会员额度或实际账单。没有新增自动重试选项。

## 权限矩阵

| 层级 | 当前能力 | 固定范围/确认 |
| --- | --- | --- |
| 数据读取 | 选定的频道文字；指定的已批准任务 | 本店、当前可见频道；不发送附件；工作流仍受频道策略和来源消息检查 |
| 草稿建议 | 翻译、印尼语消息、中文报告、任务说明/进度/提醒；PR256 的受控工作流草稿 | 管理员私人草稿；生成不代表发送或事实核实 |
| 需人工确认 | 发布消息、批准计划和验收任务 | 核对内容与频道成员；主管保留批准和证据验收权 |
| 禁止动作 | AI 自行决定退款、工资、处分、采购、改价或验收证据；越店/越频道操作 | 本次不更改后端边界 |
| 尚未接入 | 销售/库存的模型读取与经营执行 | 只显示未接入；原 `ai.operations.policy` 草稿可只读查看，页面不再提供假开关或保存入口 |

已有本地销售/补货预测不等同于此 MiniMax 连接，也不因本页保存获得新的模型权限。工作流队列的配置、审批与人工发布继续由原入口管理。

## 保存和连接状态

- 本地草稿与已保存配置分开；始终展示已保存地区和版本。保存缺项会定位密钥、目的地确认或费用字段，保存失败保留所有表单输入。
- 保存成功不等于连接成功。编辑草稿时隐藏旧成功状态；保存新版本后旧验证失效。
- `POST /api/team/ai/connection-check` 只接受 `expectedVersion`、`requestId` 和 `consent:true`。使用已保存密钥，发送固定短测试文字，输出最多 32 token；不包含员工文字或业务数据，不改变配置版本、启用状态或工作流自动发送状态。
- 返回结果包含配置版本、地区、模型及时间。明确拒绝为 `failed`；超时/无可靠结果为 `uncertain`；旧配置结果不投影为当前成功。过期 `checking` 按结果不明显示。
- 请求 ID 幂等；同版本存在进行中或结果不明测试时，新的请求也不会再次外呼。界面仅允许刷新状态，不自动重试。网络响应丢失先标记待核实，避免点击重试增加费用。
- HTTP 500/502/503/504、其他无可靠结果的响应、网络中断、超时和无效结果均为 `uncertain`。仅带匹配 HTTP 类别证据的 401/429 请求拒绝显示 `failed`；这只说明请求被拒绝，不证明未计费，原保守预留不会被清除。旧 `failed` 记录若没有明确拒绝证据，读取和新请求检查均按结果不明处理。
- 前端自己的网关 5xx/408 或网络响应丢失也保持待核实，不能直接再次验证。旧版本请求晚到时必须同时匹配请求 ID、配置版本、地区和模型，不能覆盖新版本结果。改地区、更换/移除密钥或后续成功均不删除旧请求记录或核销旧预留。
- 连接验证与原草稿生成复用凭据处理、固定地区端点、`ai-budget` 锁、每分钟限流、费用预留和结算。失败/不明结果保留费用预留。预算不足在外呼前拒绝。
- 真实 User/Staff 身份在预算锁内与返回结果前检查；停用账号不能取得验证结果，审计记录原请求的真实用户。测试不会改变最后管理员保护。
- 清除密钥使用单独的确认动作，同时暂停沟通 AI；取消不会写入，不放置常驻“清除”复选框。

## 其他页面的清理准则及范围

本次不批量改业务页面。后续按页面逐一核对真实能力和操作后再清理：

1. 员工沟通/AI 草稿：保留一次外发目的地与费用确认、来源/证据说明、人工发布边界；删除重复按钮解释。
2. 工作流队列/运营计划：保留来源消息、版本、主管批准、证据与异常/费用不明状态；不把生成、发送、执行、完成合并成一个“成功”。
3. 员工权限：以实际生效角色和门店范围为主；不以职位或模板名称替代已分配权限。
4. 退款、工资、处分、库存审批：保留金额、核实、审批人及不可逆影响的就地短提示；不替换现有业务确认。
5. 模型分析/预测页：区分模型调用、本地规则和未接入能力；不以规划文案制造可用入口。

每页只保留用户决策所需的隐私、费用和不可逆影响，在触发位置出现一次。产品页面不解释内部协议、加密、锁或未来扩展。状态、错误字段定位和真实能力标签优先于补充长段落。
