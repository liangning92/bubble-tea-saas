# 采购实付与录入更正

采购录入使用物料、数量、规格单位和该物料实际支付总额（整数印尼盾）；多物料采购按实际分摊付款逐项填写。规格换算保存原数量与单位及库存数量，单位成本保留小数，配方按库存加权平均成本计算，最终商品成本按现有整印尼盾规则保存。

例：2.3 kg 实付 Rp160,000，单位价格 Rp69,565.217391/kg、Rp69.565217/g。采购保存时生成关联财务支出，财务金额仍按现有分单位存储，收货不重复入账。当前单笔实付总额上限 Rp21,474,836（财务整数列容量）。历史采购不推定已经付款。

待处理采购允许有权限者修改并记录原因、版本及旧新内容；员工仅能改/取消本人采购。完整未消耗批次支持撤销收货，保留原出入库历史后重新修改/收货。已经消耗的批次通过现有库存调整流程处理。取消采购保留支出，退款必须在实际收到后显式登记一次，生成关联负支出，不能在支出页直接修改关联金额。

补卡、加班、换班、请假、报销增加本人待审批申请修改入口。补卡、加班、换班支持撤回；请假与报销沿用原取消。批准后记录不能覆盖。会员资料修改保留积分与余额。卫生任务仅未开始时允许改安排。押金允许更正应收总额、撤销未关联工资的扣款/退款；已扣金额与已退金额约束仍保留。账户转账支持一次性账务冲销，不执行银行转账。各更正操作留存原记录与审计。

采购页面保留新增、筛选、审批、取消、收货、供应商、日期、经办人与全部物料明细；新增统计、搜索及看板/列表切换。看板按待收货、待审批、已收货、已取消分列。商品/物料名称、数量与价格优先，完整编号可展开和复制。后台一级导航不变。
