# 电视抽奖动画与券码

后台「营销 → 促销 → 活动」选择消费抽奖。奖品名称、扇区颜色、库存与权重仍在该活动中设置；「应用马卡龙配色」只更改颜色，保存活动后预览与电视同步。新加奖品默认使用柔粉、奶黄、薄荷、浅蓝、淡紫、蜜桃与浅青。页面背景沿用YOUME粉色的马卡龙层次，文字按奖品颜色自动选择深浅，扇区保留原始设置值。

符合条件的已完成订单由服务器唯一开奖。唯一互动屏接收结果后，显示订单号，倒计时3秒、跑马灯方块跳动减速6秒，然后展示对应结果6秒；方块不重新抽取，也不更改概率。连续订单排队展示，完成后才确认事件。解除绑定或停用时取消展示，不错误确认；后台页隐藏时不会跳过整个过程。动画期间音乐暂停，结束恢复。

后台电视管理的「预览」可选择当前活动奖品，点击「预览抽奖动画（不发奖）」。播放器以内嵌文档加载，通过同源来源、窗口与加载握手校验，失败明确显示重试提示。演示不创建订单、不扣库存、不生成或发放优惠券、不确认真实电视事件。关联代金券的奖品可演示券面，示例码明确标注不可核销。

活动发券会自动生成独立YOUME券码，每张默认仅可使用一次。中奖优惠券在结果页显示金额、门槛、有效期与券码，停留30秒供顾客拍照。后台权益记录也保留券码。后台手动创建优惠券时券码可留空，由服务器自动生成；保存后进入详情展示券码，新券固定限用1次。顾客下次将照片给收银员，在结账的优惠券输入框输入券码，验券仅查询，订单完成后才核销；使用次数、门店、时间和门槛在后台再次校验。旧ACT券码兼容收银端的大写输入。

长期券使用已有必填日期字段的9999年哨兵值，界面和券面显示长期有效，凭码可转赠且只能核销一次。当前活动配置：原voucher关联Rp2,000 / 满Rp16,000，权重35、库存99；新增Rp4,000 / 满Rp20,000，权重5、库存100；其他奖项不变。

无数据库结构修改。发布受影响API、后台与Android TV APK，不构建Windows POS安装器。Android原生播放器必须更新到包含动画的APK：2.0.8可在程序升级入口在线更新，旧2.0.7需先手动覆盖安装新版。保持相同签名，不卸载，保留配对和媒体缓存。

验证记录保存在output对应任务目录。区分隔离浏览器/数据库测试、真实后台预览以及电视实机验收；没有连接真实电视时，不把Web预览当作电视实机通过。不向生产创建测试交易。
