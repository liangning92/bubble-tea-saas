# 后台 UI 优化与库存结构整理

一级导航保留原有九个模块与顺序。所有修改限于后台及相关检查，不修改营业数据库、价格算法或库存审核权限，不发布新的电视 APK。

## 使用变化

- 手机端采用抽屉侧栏，菜单关闭后内容占满屏幕；支持 Escape、焦点恢复和遮罩关闭。二级入口横向滚动，当前栏目自动进入可见范围。
- 库存二级入口分为：库存与物料（清单、出入库记录）、采购与补货（补货建议、采购/收货、供应商）、库存作业（加工、员工领用）、盘点与审核、库存预警（中心、规则）、用量与预测（消耗分析、原料预测）。原路径及业务功能保留，每组附操作说明。
- 手机库存清单、盘点明细显示为有字段标签的卡片；桌面保留表格。盘点历史、差异原因、审核及成本权限保持现有规则，摘要和补货页面响应式排列。
- 电视新店空状态显示内容→屏幕→配对步骤；没有屏幕时不显示无法提交的配对表单。配置使用可访问弹窗，固定保存区；分类、产品、规格、素材、音乐分组折叠，支持搜索、选中数量和缩略图，可清除不可用选择。
- 媒体库统一按钮样式，小文件显示 B/KB，上传显示进度；图片/视频大预览支持焦点限制、Escape 和关闭后的焦点恢复。音频仅在预览内启用控制，避免卡片按钮内嵌交互控件。
- 渠道调价先生成草稿，显示基础价、当前渠道价和保存后的价；输入不发送写请求。空值禁止保存，0%可明确保存为零价格。批量比例先预览当前筛选商品，只填入草稿，并保留启用状态。保存成功的行清除草稿；失败的行保留修改并显示可重试错误，不宣称整个批次原子成功。
- 门店信息统一为显式保存，持续显示未保存/保存中/已保存；保存前集中展示修改值，时间/日期格式不再改变选项就写入服务器。失败保留草稿和错误说明。
- 营销活动表单增加分区跳转与固定保存区，宣传图可从媒体库选择，原URL输入兼容保留；规则、参与范围、发布前核对保持原逻辑。
- 产品分析的策略建议优先展示，四象限图可折叠；详细数据继续按需加载，产品图库、放大及偏好保留。

## 本地验证

后台类型与生产构建通过；相关单元79项、服务审计5组32项、隔离上传代理验收通过。真实 React 页面覆盖手机抽屉、弹窗焦点/Escape、电视搜索与内容保存、素材预览、调价零值/空值/失败重试/批量草稿、门店集中确认、库存分组。

盘点检查覆盖记录/提交/审核、历史和出入库深链接、成本权限、三语言及手机卡片；媒体/产品检查覆盖上传、选择、分析折叠和图库；营销23页中文/英文/印尼语检查及活动创建、POS同源报价、电视事件确认兼容检查通过。

所有操作验证使用隔离的合成数据；未在生产创建测试交易。正式 CI、后台镜像及公网验收记录保存在工作区 output/admin-ui-optimization-20261014；正式检查失败时不发布。
