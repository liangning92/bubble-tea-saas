## 优先优化项

| 优先级 | 页面/范围 | 已观察的问题 | 建议 |
|---|---|---|---|
| P1 | 后台公共框架（尤其手机上的电视管理） | 390px 视口默认展开 256px 侧栏，内容只余很窄空间；二级导航及标题被逐字换行，手机初次打开难以使用 | 小屏默认收起，侧栏改抽屉；内容占全宽；二级导航可横向滚动。保留一级模块、顺序和归属 |
| P1 | 电视管理及配置 | 新店无屏幕时大片空白，配对目标不可选但表单仍展示；内容配置各分类/产品/规格连续长列表无搜索/缩略图；默认配置表单已约1028px高，多产品时更长；保存及错误反馈在底部，缺少规范 dialog/focus/Escape | 空状态提供“设置默认内容→添加屏幕→配对”引导；配置分组并显示选中数量；素材缩略图和搜索；固定保存区和就近错误提示；统一可访问弹窗 |
| P1 | 渠道商品定价（源码） | 价格输入 onChange 每次触发写请求；没有修改前后对比、明确提交或行级失败反馈；批量±百分比按钮直接修改，缺少影响范围预览 | 编辑草稿后保存；显示原价、调整值、结果；批量操作预览商品数和价格变化；行级保存/失败/重试。0和空值语义另列功能检查，不当作视觉问题 |
| P2 | 媒体库及媒体选择 | 页面大量使用 btn/btn-sm 类，但 CSS 没有这些基础定义，重命名、引用、删除看起来像挤在一起的文本；小文件显示0.00MB；预览固定h-40，弹层没有完整焦点与Escape处理 | 统一按钮组件与间距，删除使用明确次级危险操作；自动KB/MB；大图/视频适配预览；上传进度；对话框焦点和键盘关闭 |
| P2 | 营销活动编辑 | 产品、规则、参与范围、时段、宣传与发布放在长表单；保存前预览位于末尾，操作时需要反复滚动；宣传图仍用Image URL文本输入 | 保留现有规则，按分区/步骤组织；侧边或折叠摘要；固定保存区；从已有媒体库选图，保留URL兼容 |
| P2 | 系统设置（源码） | 输入失焦自动保存，又有手动保存按钮；成功提示仅2秒，用户不容易判断哪些字段已经保存；错误反馈较笼统 | 明确统一保存模式；显示待保存、保存中、已保存和字段级错误；重要店铺/时区设置集中确认 |
| P2 | 库存盘点（源码） | 概览固定grid-cols-3；明细表min-width860px，手机需要横向查找商品和数量 | 小屏摘要单列/双列；明细用卡片或固定商品/数量操作列；保留盘点数据及现有业务流程 |
| P3 | 产品分析/详情 | 桌面信息丰富但同时包含策略、图表、产品偏好、明细，信息扫描成本较高 | 主指标与建议优先；高级图表/明细折叠；保留已有懒加载、产品图库和图像放大，不因改版移除有效功能 |
