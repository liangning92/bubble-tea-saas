# 员工自定义规则

入口：员工 → 工资 → 计薪与休假。沿用一级导航，保留工资、报销、试用期、押金等模块。

本页保存门店计薪与休假规则：固定带薪休息天数、足月/按在职比例/当月在职适用方式、禁止休假的星期、半天假、年假/病假初始额度、工龄增假、日薪扣款折算天数、加班折算工时、全勤奖最低出勤天数及金额。旧门店未配置时沿用原值，保存后按门店读取，不在员工浏览器写死周末禁假。

后台的请假提交、审批、工资重新测算均读取当前规则；员工端显示门店当前的休假限制。新接口只向员工返回休假星期和半天假设置，不返回薪资规则。管理员修改权限保持不变。旧客户端只修改部分字段时保留其他已配置字段。

固定带薪休息：按比例时向下取半天，任何方式均不超过在职期间剩余可计薪天数。跨试用期按在职期间工资标准加权折算。月薪基本工资仍按当月自然日折算；日薪扣款基数与加班工时单独配置。全勤奖仍受员工功能开关控制。

新初始化的休假余额使用门店年假/病假与工龄规则；读取余额不再先生成零额度导致自动初始化失效。已有余额（包括管理员设置的零额度）、已发工资、已保存的个人规则不自动覆盖。年度余额使用请求年份，关闭自动分配时不分配额度。

页面保留原有带薪休息与保存操作，新增规则按计薪、休假、额度、扣款与加班、全勤奖分组；其他员工规则提供现有考勤、请假类型/证明、试用期、押金、积分和员工功能入口。窄屏单列，宽屏双列，星期复选框自动换行。

验证范围：门店规则保存/读取、旧配置兼容、周末放开、任意星期禁假、工龄/年假/病假额度、既有余额保留、半天假后端校验、部分月份带薪休息、实际工资折算与全勤奖配置、访问声明、类型与三语检查。真实 Web 与发布证据保存在 output/staff-rules-custom-20261015。

## 考勤入口整理

按记录查询、申请审批、规则设置三组展示子入口。考勤改为考勤记录；员工事项审核仅展示申诉、资料、工资异常及学习进度，月度迟到规则移至独立规则页。原八项功能全部保留，增加月度迟到及请假类型可见入口；已有地址继续有效。月度迟到页保留仅管理员访问及影响预览/保存重算流程。加载后自动回显当前月已保存规则，不再默认显示停用。
