# Hermes 自然语言、等待与回复语言修复

不新增问句匹配。未命中已有快速查询的自然语言进入原始 Hermes SDK 和已购模型。当前账号、店铺、角色、字段和会话受众权限仍由后台逐次校验，模型不拥有授权权力，账号名称不参与判断。

首次请求前的耗时包含容器和源码校验、SDK 模块加载、Bedrock 依赖的运行时安装尝试、模型元数据探测及额外的会话标题生成。保持原始 SDK SHA 与完整源码校验；依赖移到镜像构建，模块在私有运行环境准备阶段加载，使用 SDK 支持的模型配置关闭无关探测、标题和后台复盘。正常原生会话日志与账号隔离保留。

打开已授权且已接入 Hermes 的会话后异步准备当前账号与当前受众对应的进程；工作进程重启时最多准备两个最近使用的账号。准备不提交模型请求、不配置请求凭据、不读取业务数据。权限或受众变化使用新隔离标识。资源不足时不终止正在运行的任务。

消息保存发送时的界面语言，离线重试也保留该语言；中文消息覆盖语言回退。语言与原消息一起校验，等待、超时、失败与异常重复拦截使用同一语言。模型按当前问题语言回答，不按员工身份强制印尼语。

验收要求：隔离测试验证三种未匹配固定句式的自然语言可进入模型通路、当前账号权限、三种语言超时、无权成员和权限撤回。真实原生 SDK 测试记录准备、提交、首次模型调用时间并验证仅有业务必要模型调用。上线后在已有管理员与 Hermes 私有会话用多种自然问法验收；不联系员工，不修改账号权限。活动链路仅使用不发布、不展示、优惠为零的自检草稿。

真实验收发现，旧营销对话会使通用能力问题漏掉库存、财务等已授权领域。当前能力索引改为由后台原生路由与实时账户权限自动生成，并通过原始 SDK 的 instructions 字段作为系统指令传递。历史上下文仅用于解释当前问题中的明确引用，旧活动不再自动分类新问题或插入创建指令；不会清空会话历史或按问句新增匹配。

活动草稿的执行授权不再依赖创建动词白名单：模型理解当前请求，后台继续校验实时账号、当前店铺、受众、原生活动字段和幂等回执。发布仍要求明确发布指示；问题、引用和附件本身不构成写入请求。原生运行结束或超时时，按实际持久化回执核对自然语言创建结果，不根据问句猜测成功，不重放未知写入。隔离测试覆盖未命中旧动词识别的管理员草稿创建、无权账户拒绝和原生失败后的已保存回执核对。

口语化跨日期营收实测暴露了关键词提示之外的目录→说明→执行串行发现开销。每个原生请求现在附带由后台实际路由 schema 自动生成的已声明查询及活动契约，不按提问措辞筛选，worker 用实时账户权限补充 accountAccess。已有契约直接执行，未知模块仍可查原生目录，不能以旧聊天结果替代本次实时查询。该索引只含接口元数据，不预读业务数据，也不授予权限。

后续实测确认：口语营收查询已直接调用正确接口，数据库耗时约 95 ms，但返回四万余字符的订单与班次明细拖慢模型总结。原生营收查询新增可选 view=summary，保留金额、日期、统计口径与聚合分组，省去明细；默认 detail 保持现有管理页行为。账户、路由契约、店铺与时钟改用原生 SDK 本次临时系统上下文，不再逐轮写入聊天正文。原有会话记录保留，未经用户请求的旧业务不自动恢复。原始 SDK 隔离验收验证上下文标记进入模型系统消息、没有进入持久化聊天记录。

实时查询实测进一步发现模型复用历史接口哈希，导致 BACKEND_CONTRACT_CHANGED。原生入口现将执行版本绑定到服务器已发给本次请求的契约快照，不由模型选择；真正的线上版本变化仍由原生执行校验拒绝。对本次已声明支持 summary 的查询投影，智能体缺省使用汇总，明确 detail 保留明细。直接后台客户端和外部工具的版本校验不变，不按账号名称或问句措辞处理。

连续实测中，普通今日领用虽已在 59 ms 返回数据，累积的旧接口输出仍让两轮模型调用超时。现使用原始 SDK 已支持的 conversation_history 请求参数，只携带当前账号与全部受众均可见的最近对话（最多 6 条、合计 6000 字节），不载入整段历史接口 JSON。旧聊天及原生 SDK 会话记录完整保留；隔离原始 SDK 试验证明同一 session 的旧记录前缀不变、当前问题仅追加一次。时钟移到本次输入，避免时间变化扰动固定系统上下文；已有全局原生契约时不重复添加关键词提示。窗口外的含糊引用应查询获准来源或追问，不编造历史。清洁派工使用空窗口，不转移经理私有历史。

普通聊天不再因“详细、全面、审计”等词自动获得十分钟运行预算，统一使用有界的前台期限。服务端显式工作任务仍可单独配置预算，不能由问句词汇隐式延长。历史窗口先按当前所有受众权限过滤，个人记录不作为无资源归属的历史摘录传递，需按当前个人范围重新查询；原 UI 可见性策略保持不变。
