# 消息阅读与业务处理状态（2026-10-28）

消息中心默认显示未读，保留全部、已读历史、聊天、培训更新和待处理筛选。库存、AI 工作等业务待办使用“待处理”标签，只有真实审批请求使用“审批待处理”；顶部审批计数仍只统计当前有权处理的审批节点。

直接进入业务页面也会同步个人阅读回执：只有当前路由已经加载、实际进入可见区域且对应消息对象的记录才确认已读。审批记录需匹配已加载的业务状态；库存预警需匹配当前发生批次和级别，AI 工作需匹配记录版本。加载失败、隐藏记录、其他对象、旧状态和旧预警版本不会被提前确认。聊天和培训仍使用各自原有的阅读协议。

后端确认已读后，客户端保留本账户会话内的确认集合，防止更早发出的轮询把已读覆盖回未读。接口失败允许下轮重试；切换账户、门店或登录会话清空确认集合并中止旧请求。阅读不执行审批、不改业务状态、不关闭尚未解决的预警，也不替换来源记录的实时权限核验。

验证包括直接访问、延迟加载、旧审批状态、预警复发、请求失败重试、已读与旧轮询竞态、账户切换，以及中英印尼语的桌面、平板和手机布局。原有两端消息中心的聊天、培训、审批、超时和身份切换浏览器流程保留回归。正式页面验收与发布版本保存在本次 output 目录。
