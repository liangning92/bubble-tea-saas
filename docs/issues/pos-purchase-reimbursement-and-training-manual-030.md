# POS 采购报销、交班小票与培训手册

用户确认：POS 费用仅用于员工购买门店用品后的报销记账，直接进入财务支出，无审批；POS 不查看其他后台费用。保留简短顶部“费用”，弹窗“采购报销”、按钮“记账”。必填类别、数量、总金额及采购说明。

- 专用 /expenses/pos 以登录人和门店过滤来源；旧 cashier 通用费用列表也限制为本人 POS 记录。
- 请求 UUID 防重复，同号不同金额/数量/内容拒绝；费用与数量审计在同一事务保存。POS 使用整数 Rp，财务保留原金额分单位，统一转换。
- 后台财务支出显示采购数量。没有自动付款或钱箱出金；员工实际取得现金时另记现金动作，避免重复费用。
- 交班按开班至交班时间读取本店 POS 采购费用，保存封存快照，打印类别/数量/金额和总计。明确“记账不等于现金付款”及销售仍需核对；不打印未经验证的财务结算凭证。
- “现金”页面补打已关班交接记录；接口严格校验门店，旧班次没有快照时印“待核对”，不会伪造 0。
- 修复钱箱/任务入口和实际任务接口数组读取；交班保留未付款挂单。
- 培训资料增加受保护 PDF 上传、草稿预览、发布后员工读取。仅本店管理员可上传，非发布文件及跨店文件不能被员工读取；20 MiB 限额、格式/UUID校验、私有文件存储。

本次 HTTP 用例运行于任务创建的 SQLite/PostgreSQL，覆盖来源隔离、单位一致、数量持久化、重试/冲突、边界时间、补打、PDF 权限和下载字节一致。Chromium 实际 POS 页面输入数量3、总金额35000并提交，只调用个人报销接口。打印文本验证三种语言及58/80mm，门店实体打印机输出尚未远程验收。
