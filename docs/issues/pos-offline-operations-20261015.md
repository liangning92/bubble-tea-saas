# POS 连续 30 天离线经营

## 本次实现与验证范围

已联网准备的本机使用最后一次成功同步的门店资料、签名商品价格和员工权限，支持30天内的密码登录、现金收银、外部已收款人工记账、开班、现金收支、采购费用、交接班、历史订单、本机挂单恢复与小票补打。授权和活动价格快照有效期一致；第31天不得继续使用过期授权。普通退出保留密码验证缓存，账号与权限按员工、门店和后台隔离，不保存明文密码。

外部银行卡、电子钱包和静态 QRIS 的人工记账沿用收银员确认流程；记录不是银行到账证明，不会在断网时调用支付机构扣款。非现金计入营收，从应有现金中排除。退款可离线登记申请，金额和审批恢复后核定，登记申请不执行退款、不恢复库存、不减少钱箱金额。

用户已确认门店只有一台 POS，连续断网30天期间以本机账本为准。已增加按员工权限隔离的完整会员目录缓存、手机号/卡号查找、会员积分连续记账及已领取优惠券本机核销。会员目录分页全部成功后才原子替换；本机尚有会员订单待补传时保留原目录和流水，不用服务器旧数据覆盖。商品与会员扫码在网络故障时读取本机目录。

会员订单、抵扣积分、按原消费日和原规则获得的基础积分、用券记录及原签名快照与收款一起落盘。恢复时按原顺序同事务扣积分和核销优惠券，重试同一订单不再扣减；有效期以消费时点核验。服务器只增减流水，不覆盖会员整个积分余额。后台额外赠送的积分保留；若后台已扣减导致权益不足，本机凭据保留为待核对，不静默改价或丢弃。会员储值余额当前只读缓存，尚未新增离线储值付款或充值界面。退款执行、新会员离线注册、任务/考勤依赖及完整真实页面验收仍未完成，不能宣称“全部 POS 功能离线”已经上线。

## 数据与恢复约定

- 班次、订单、现金收支、费用及退款申请先在 IndexedDB 持久化；本地写入失败不得清空未收款购物车或发出小票。
- 开班→本班订单与收支→交班→下一班按依赖补传。原始操作 UUID、订单号、时间、价格、税率和请求重试时不重建；服务端效果与操作回执同事务提交。
- 离线订单保留发生时间；不能用补传时间记入恢复时的新班次。关闭前核对完整离线订单清单；任何未入账订单保留为待处理，不能跳过后把该班同步完成。
- 当前班次的服务器汇总与已包含订单号、操作 ID 在同一数据库快照读取。本地只叠加未被该快照包含的事实，防止服务器已提交但回复丢失时重复计算。
- 交班先冻结本机报告，恢复后另存服务器核对版；两者均保留。报表保留实际金额，数据库整数列不以截断或四舍五入伪造对账结果。
- 恢复同步不触发打印或钱箱。手动补打使用原始已保存小票，一份、不弹钱箱。交班单区分本机待同步与服务器已同步状态。
- 连接恢复后，POS 有有效登录会话时自动补传。正常服务器令牌过期时，使用当前进程中由员工亲自输入的密码进行正常重新登录；不绕过服务器权限、不延长原令牌。
- IndexedDB v2 只增加门店/班次索引，不删除旧订单。普通浏览器清除站点数据会删除其本机账本；桌面端需保留原用户数据目录。
