These named read handlers are unreachable. The initial frontend-only mock proved component navigation, NOT actual analysis endpoint reachability. This batch does not reorder backend routes or change permissions/algorithms. Final dashboard exposes analysis as unavailable without navigation/HTTP, and direct /inventory/consumption-analysis is a context-preserving unavailable landing page instead of a blank route. Unshipped ConsumptionAnalysisPage changes were archived under /tmp and original source restored. Actual Express matching/terminal-handler synthetic tests retain this blocker evidence; auth/data are not certified by those tests.
