# 调班申请：双方确认与流程进度（2026-10-18）

- A 必须选择本店其他在职员工 B；提交后进入“等待对方确认”。
- B 在 APP 内收到邀请弹窗，可同意、不同意或稍后处理；调班页保留待处理入口。已订阅手机推送的员工继续由既有提醒 worker 通知。
- B 同意后进入后台队列，后台批准才在同一数据库事务中互换双方排班；B 不同意直接结束。后台拒绝与撤回均有独立结束状态。
- 双方历史均显示申请人、调班人员、日期、班次、原因、审批备注与四步进度条。打开 APP 时轮询邀请；流程页后台刷新状态。
- A 修改待处理申请会清除 B 的确认；B 的回应须携带当前版本，旧页面、重复点击及并发回应不会覆盖新状态。
- 既有配置中的“调班双方确认”保留并固定启用，不能再跳过确认。旧的未指定 B 申请需由 A 编辑补充。
- 无数据库迁移。仅发布 API、admin、staff；保留导航、申请编辑/撤回、班次选择、原因、历史、筛选、刷新和审批操作。
