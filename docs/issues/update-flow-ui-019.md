# 更新操作与后台说明修复

用户反馈后台说明文字过多，且点击 POS 内的安装更新后仍反复提示。

正式 2026.10.309 安装包已解包，确认 app.asar 内版本为 2026.10.309，文件 SHA256 与正式发布记录一致。源码中的安装按钮调用被拒绝的 install-update IPC；下载就绪不表示安装完成。错误通知还使用“有可用更新”标题，关闭后同版本定期检查可再次弹出。

本次删除不可执行的安装按钮。下载完成后提供“打开安装文件夹”，用户完成交易、关闭 POS，运行安装文件并确认备份升级。继续保持禁止静默覆盖和禁止自动退出收银，未绕过原数据库升级检查。界面展示实际运行版本；同版或旧版通知被过滤，同一版本关闭后自动提示暂停一天，新版本仍提示；自动检查的网络错误不弹窗打断收银。错误标题与更新标题分开。修正新版本通知的三语版本号插值。

后台保留必要业务状态、金额、待接入及错误提示。退款规则、支付核验说明、盘点解释、外卖能力及 AI 草稿说明改为默认折叠帮助；普通页面不再显示内部门店 ID、原始时间戳及重复说明。业务权限、交易校验及审批确认继续生效。

Windows 升级验收新增已安装 app.asar 版本与构建版本一致的检查，正式发布门禁要求该结果通过。现有收银机的实际安装路径与运行版本仍需设备侧核对；本机解包验证不能代替现场验收。

设备巡检新增功能暂缓发布，工作已保存于工作区 recovery/device-feature-pending，待此次反馈修复后继续。
