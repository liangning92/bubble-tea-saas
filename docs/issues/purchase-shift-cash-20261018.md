# 采购付款与交班现金分离（2026-10-18）

用户确认所有采购订单均先网络付款再购买，与任何班次现金无关。后台强制采购及采购退款使用 online_payment；收货只增加库存，销售成本保留冻结销售配方用量计算，采购付款不重复计入经营成本。支持实际付款日期。

只有明确的 drawer_cash 日常支出影响交班，绑定实际付款时刻与唯一班次。POS 离线预计现金与服务器一致；遗留客户端缺少来源时保留 unknown，不猜测。

历史修复保留原交班报告、实点和原始金额，单独展示派生复核结果。采购根据用户明确确认移出班次。其他来源不明的历史费用保留原计算并提示待核对；管理员可以核对实际付款来源、门店时间及原因，留存审计和乐观版本检查。复核不等于认定员工现金损失。

PostgreSQL 发布前备份，执行 `server/prisma/migrations/202610180001_expense_payment_source/migration.sql`。部署验证镜像后运行 `scripts/reconcile-purchase-payments.cjs --apply`，可重试，保留原付款日期和交班报告。SQLite 启动补列前自动备份并验证备份，不修改旧迁移校验和。

保留采购看板/列表、筛选、供应商、数量/单位/价格、收货、撤销、退款，以及费用类别/导入导出、班次指标/订单/预警/员工和交班操作。仅增加付款说明及历史核对；采购不提供钱箱选项。真实 Web 和响应式证据记录在本批次 output，控制连接不可用时不得宣称真人工验收完成。
