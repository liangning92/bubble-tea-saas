The user clarified that updates must retain the login as well as automatically install/reopen. POS authentication used sessionStorage, which does not survive a process restart. The in-app updater now captures only the current session, encrypts a one-time handoff using Electron safeStorage, and restores it before the main cashier renderer mounts. The customer display cannot consume it. Handoffs expire after 15 minutes, expired JWTs are refused, backend identity must match, logout/no-session states are never restored, and passwords are excluded. Windows publication requires the exact packaged module to save and restore the encrypted state across two separate standalone Electron processes.
