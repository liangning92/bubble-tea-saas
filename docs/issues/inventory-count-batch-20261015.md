# 连续盘点与统一保存（2026-10-15）

员工端和后台盘点均使用同一录入组件。默认一次带出全部物料；员工端选择部分物料时支持搜索、选中搜索结果和清空选择。连续填写实盘数后统一保存，差异说明折叠且选填。支持搜索、未盘/差异筛选、Enter 移至下一项和现有单位/包装换算。

空白不计作零，不自动复制账面库存；已盘记录不能通过清空数量覆盖。允许保存部分物料并继续盘点，仍须所有物料已盘且没有未保存输入才可提交。保存只记录观察及差异，审核通过后才调整库存。盘点状态、盘点人、进度、差异汇总、观察后出入库、成本权限、历史明细与调整记录保留，一级导航不变。

新增 `PUT /inventory-counts/:id/items` 复用 inventory.count 权限和后台身份。所有明细在同一事务中保存；逐项核对门店、盘点单、状态、库存值和版本。任意项失效整批回滚，保留前端输入；用户重新核实并显式刷新账面快照后可重试。兼容旧单行接口，移除保存和审核时的差异说明必填限制，保留原观察边界及库存调整去重规则。
