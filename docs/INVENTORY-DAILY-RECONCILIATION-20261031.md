# 每日耗用与盘点库存核对

每日耗用页默认今天，独立比较实际登记出库和订单冻结配方理论量，不依赖盘点。保留用途、加工产量、可制作份数、预警及既有导航。历史配方证据不足仍显示真实已知量和缺失原因，不补造理论量。保留已核实部分数量，并列出实际缺失配方的商品及次数；部分证据不作为全量差额计算依据。

盘点库存核对独立使用上次已完成实盘＋期间实际入库－期间实际出库，与下一次实盘比较。15 kg－3 kg＝12 kg；实盘不同即提醒。已提交待审核的实盘也可比较；审核完成不抹去差异，后续一致实盘使旧提醒解除。订单估算、盘点调整和仓库内部转换不重复计入物理出库。完整性以盘点证据、台账序列和单位边界校验；不满足时明确缺失，不把未知作为零。只有一次有效基准时展示应有库存，等待下次实盘。

原料流水查询在服务端按名称（含翻译）、说明、供应商及订单参考筛选后分页加载全部匹配项，避免最近1000条截断产生假空结果。显式时间戳保留门店边界，日期值按门店时区解释。自选日期编辑与查询分离，完整性、年份和先后校验后才应用；显示实际查询范围。统计随筛选，实际出库按原料分别汇总，小数保留最多六位。请求失败与无匹配分别说明；已有成功数据保留。出入库登记、更正、导出、照片证据等模块保留。

本地针对性检查：后台及服务端类型检查；纯函数/路由检查11项；隔离SQLite业务流程24项（包含无盘点每日量、15/3/12、待审核差异及审批后持续、后续恢复、门店午夜边界和分页搜索）；合成页面三语言、状态恢复、日期、权限、失败、桌面1365/平板768/手机390布局。合成数据仅用于辅助验证，不修改正式库存。
